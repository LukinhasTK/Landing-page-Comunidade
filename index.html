Projetos

Objetivo

Tornar o ensino musical acessível e despertar novos talentos.

Como funciona

Aulas semanais com professores voluntários para iniciantes.

Estrutura

Espaço comunitário com instrumentos disponíveis para aprendizado.

Quero Ajudar

Este projeto tem como objetivo oferecer aulas gratuitas de música para pessoas de todas as idades, especialmente para aqueles que não têm condições de pagar. Com a ajuda de professores voluntários, queremos criar um espaço de aprendizado, acolhimento e desenvolvimento dentro da nossa comunidade. Para que isso se torne realidade, contamos com a sua ajuda.
